🔍 اختبار اتصال Firebase

📋 إذا ظهرت أخطاء في الأذونات:

  1. اذهب إلى: Firebase Console
  2. اختر المشروع: the-real-world-review
  3. اذهب إلى Firestore Database > Rules
  4. استبدل القواعد بهذا الكود:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{collection}/{document=**} { allow read: if true; allow write: if true; } } }

⚠️ ملاحظة: هذه القواعد للاختبار فقط. استخدم قواعد أكثر أماناً في الإنتاج.
