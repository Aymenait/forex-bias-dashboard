## 🎯 كيفية إضافة تقييم جديد | How to Add New Review

### للعملاء | For Customers

1. **افتح الصفحة الرئيسية** | Open Homepage
2. **انتقل إلى قسم التقييمات** | Go to Reviews Section
3. **اضغط على "أضف تقييمك"** | Click "Add Your Review"
4. **املأ النموذج:**
   - الاسم | Name
   - المنتج | Product
   - التقييم (1-5 نجوم) | Rating (1-5 stars)
   - التعليق | Comment
5. **اضغط "إرسال التقييم"** | Click "Submit Review"

### للمطورين | For Developers

#### إضافة تقييم يدوياً في الكود | Add Review Manually in Code

افتح ملف `script.js` وأضف التقييم في مصفوفة `realReviews`:

```javascript
const realReviews = [
    // ... existing reviews
    { 
        name: "اسم العميل", 
        product: "The Real World", // or "ChatGPT Business" or "Adobe Creative Cloud"
        rating: 5, 
        comment: "التعليق هنا", 
        date: "2024-12-02" 
    }
];
```

#### إضافة تقييم في Firebase | Add Review in Firebase

```javascript
// في Firebase Console
Collection: reviews (or chatgpt-reviews or adobe-reviews)
Document: Auto-ID
Fields:
  - name: "Customer Name"
  - platform: "The Real World"
  - product: "The Real World"
  - rating: 5
  - comment: "Review text"
  - timestamp: serverTimestamp()
  - approved: true
```

## 🔧 التخصيص | Customization

### تغيير عدد التقييمات المعروضة | Change Number of Displayed Reviews

في ملف `script.js`، ابحث عن:

```javascript
const displayReviews = reviews.slice(0, 6); // عرض 6 تقييمات
```

غيّر الرقم 6 إلى العدد المطلوب.

### تغيير ألوان النجوم | Change Star Colors

في ملف `script.js`، ابحث عن:

```javascript
star.style.color = '#ffd56f'; // لون النجوم الممتلئة
star.style.color = '#666';    // لون النجوم الفارغة
```

### إضافة منتج جديد للتقييم | Add New Product for Review

في ملف `index.html`، أضف خيار جديد في القائمة المنسدلة:

```html
<select id="review-product">
    <option value="The Real World">The Real World</option>
    <option value="ChatGPT Business">ChatGPT Business</option>
    <option value="Adobe Creative Cloud">Adobe Creative Cloud</option>
    <option value="منتج جديد">منتج جديد</option>
</select>
```

## 🐛 استكشاف الأخطاء | Troubleshooting

### التقييمات لا تظهر | Reviews Not Showing

1. تحقق من تحميل Firebase بشكل صحيح
2. افتح Console في المتصفح وتحقق من الأخطاء
3. تأكد من وجود التقييمات في `realReviews`

### المودال لا يفتح | Modal Not Opening

1. تحقق من وجود `id="add-review-modal"` في HTML
2. تأكد من تحميل JavaScript بشكل صحيح
3. تحقق من Console للأخطاء

### التقييمات لا تُحفظ في Firebase | Reviews Not Saving to Firebase

1. تحقق من إعدادات Firebase
2. تأكد من صلاحيات الكتابة في Firestore
3. تحقق من اتصال الإنترنت
