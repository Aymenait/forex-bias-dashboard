# تصحيح الأسعار داخل البطاقات

## المشكلة
كانت الأسعار داخل البطاقات (في نوافذ الدفع المنبثقة) تُحسب تلقائياً بقسمة السعر بالدينار على 230 ثم تقريبه للأعلى، مما أدى إلى عرض أسعار غير صحيحة:

**مثال:**
- السعر الصحيح: **15 USD**
- السعر المعروض في البطاقة: **17 USD** (3750 ÷ 230 = 16.3 → 17)

## الحل
تم تعديل الكود في `script.js` لاستخدام السعر الصحيح من `data-price-usd` بدلاً من الحساب التلقائي.

## التغييرات

### 1. تصحيح أزرار USDT (Crypto)
**الملف:** `script.js` - السطر 86

**قبل:**
```javascript
const priceUSD = Math.ceil(priceDZD / 230); // تحويل من دينار إلى USDT
```

**بعد:**
```javascript
const priceUSD = button.getAttribute('data-price-usd') || Math.ceil(priceDZD / 230); // استخدام السعر الصحيح من data-price-usd
```

### 2. تصحيح أزرار RedotPay
**الملف:** `script.js` - السطر 154

**قبل:**

const priceUSD = Math.ceil(priceDZD / 230); // تحويل من دينار إلى USD
```

**بعد:**

const priceUSD = button.getAttribute('data-price-usd') || Math.ceil(priceDZD / 230); // استخدام السعر الصحيح من data-price-usd
```

## ملاحظات مهمة
- ✅ **لم يتم تغيير أسعار الدينار الجزائري** - بقيت كما هي
- ✅ **تم تصحيح الأسعار بالدولار فقط** - لتتطابق مع الأسعار المحددة في `currency-config.js`
- ✅ **الحساب التلقائي لا يزال موجوداً كخيار احتياطي** - في حالة عدم وجود `data-price-usd`

## الاختبار
