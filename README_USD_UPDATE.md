## 🎨 كيف يعمل النظام

### عند اختيار USD:
```
المستخدم ينقر على زر USD
    ↓
CurrencyManager.setCurrency('USD')
    ↓
updateAllPrices('USD')
    ↓
يقرأ data-price-usd من HTML
    ↓
يعرض السعر مع رمز $
```

### عند اختيار DZD:
```
المستخدم ينقر على زر DZD
    ↓
CurrencyManager.setCurrency('DZD')
    ↓
updateAllPrices('DZD')
    ↓
يقرأ data-price-dzd من HTML
    ↓
يعرض السعر مع رمز د.ج
```

## 🔧 استكشاف الأخطاء

### المشكلة: الأسعار لا تتغير
**الحل:**
1. افتح Console (F12)
2. تحقق من الأخطاء
3. تأكد من تحميل جميع ملفات JavaScript

### المشكلة: رمز $ لا يظهر
**الحل:**
```javascript
// في Console
const manager = new CurrencyManager();
console.log(manager.formatPrice(10, 'USD')); // يجب أن يكون "$10"
```

### المشكلة: الأسعار خاطئة
**الحل:**
1. تحقق من `currency-config.js`
2. تحقق من `data-price-usd` في HTML
3. تحقق من Console للأخطاء
